# Horizon Voyages

Site vitrine responsive d’une agence de voyage sur mesure, réalisé avec React, TypeScript, React Router et Tailwind CSS.

## Démarrer le projet

```bash
npm install
npm run dev
```

## Construire pour la production

```bash
npm run build
```

Le site présente l’accueil, les destinations, les offres, l’agence et un formulaire de contact. Le logo Horizon Voyages est dans `src/assets/horizon-logo.png`.
